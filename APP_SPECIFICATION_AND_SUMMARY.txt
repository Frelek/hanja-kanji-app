1. EXECUTIVE SUMMARY & CORE MISSION
================================================================================
The Hanja & Kanji Learning Application is a mobile-first Progressive Web App (PWA)
specifically engineered to solve the cognitive overload associated with East
Asian ideogram memorization. By structuring characters into etymological,
derivative "family trees" rather than isolated lists or arbitrary frequency
tables, learners understand *why* characters look the way they do before they are
tested on them.

The app provides a seamless dual-language environment:
- Korean Hanja (한자): Focusing on Korean phonetic readings (음), native Korean
  definitions (훈), and Sino-Korean compound vocabulary used in everyday Korean.
- Japanese Kanji (漢字): Focusing on On-readings (音読み), Kun-readings (訓読み),
  authentic compound words (熟語), furigana-annotated sentences, and a strict
  pedagogical display where pure kana is explicitly printed below all kanji.

The app functions completely offline without requiring any external cloud APIs,
backend servers, or third-party CDNs. It is optimized to run as a native-like
standalone application when added to an iPhone Home Screen via Safari.

2. USER REQUIREMENTS & THE TREE-BRANCH CONCEPT
================================================================================
The user specified a precise set of architectural and aesthetic guidelines based
on an initial hand-drawn wireframe sketch:

1. Tree-Branch Layout:
   - Root elements on the left / top (Level 0 fundamental pictograms / radicals).
   - Stems branching vertically and connecting rightward to compound ideograms.
   - Each successive tier adds strokes or combines components.
   - Progressive unlock: child nodes remain locked until their parent ideogram
     is reviewed and marked as learned.

2. Visual Identity & Atmosphere:
   - "Bright, beige or smth like that": A warm, glare-free traditional parchment
     aesthetic evoking Korean Hanji (韓紙) and Japanese Washi (和紙).
   - Deep calligraphy sumi-ink typography (#231f1d) on soft beige (#f7f4ed).
   - Accents of traditional cinnabar / vermilion red (주칠 / 朱色, #c53030).

3. Dual-Language Switcher:
   - Positioned prominently in the upper right header: [ 🇰🇷 한자 | 🇯🇵 漢字 ].
   - One-tap instantaneous language switching without reloading the page.
   - Complete isolation between Korean and Japanese learning statistics.

4. Japanese Reading Invariance:
   - In the Japanese section, under every example word written with kanji, the
     exact pure kana pronunciation (without kanji) MUST be printed directly below.

5. Quizzing Placement & Scope Invariance:
   - Quiz buttons must NEVER appear next to individual words or in the modal.
   - Quizzing is accessed ONLY at the top of each category branch header.
   - Quizzes MUST strictly filter to only characters the user has marked as
     learned. Unlearned characters must never appear in quizzes.

6. Spaced Repetition (Anki SM-2):
   - A dedicated flashcard test mode with 3D card flips.
   - SuperMemo SM-2 interval calculations with Again, Hard, Good, Easy ratings.

7. Offline & Standalone Execution:
   - Must be publishable via GitHub Pages.
   - Must support iOS "Add to Home Screen" with "Open as Web App" checked.
   - 100% offline operational capacity via local ServiceWorker caching.

6. COMPLETE DATA SCHEMAS & FIELD DICTIONARIES
================================================================================

6.1 Korean Hanja JSON Schema (`data/hanja.json`)
Root Object:
{
  "branches": [ BranchObject, ... ]
}

BranchObject:
- id: string (Unique identifier, e.g., "nature", "numbers")
- name_kr: string (Korean category name, e.g., "자연")
- name_en: string (English category name, e.g., "Nature Elements")
- icon: string (Category emoji icon, e.g., "🌲")
- characters: Array of CharacterObject

CharacterObject:
- id: string (Unique identifier, e.g., "tree", "mountain")
- hanja: string (Single ideogram glyph, e.g., "木")
- reading: string (Korean phonetic reading, e.g., "목")
- meaning_kr: string (Native Korean definition, e.g., "나무")
- meaning_en: string (English definition, e.g., "tree / wood")
- strokes: integer (Total stroke count, e.g., 4)
- level: integer (Hierarchy depth: 0=root, 1=derivative, 2=compound)
- parent_id: string | null (ID of parent character, or null for root)
- components: array of strings (Constituent ideograms, e.g., ["木"])
- example_word: string (Sino-Korean compound word, e.g., "목요일")
- example_word_reading: string (Hangul reading + romanization, e.g., "목요일 (mok-yo-il)")
- example_word_meaning_kr: string (Korean definition of example word, e.g., "나무의 날")
- example_word_meaning_en: string (English definition of example word, e.g., "Thursday")
- example_sentence_kr: string (Natural exemplary sentence in Korean)
- example_sentence_en: string (English translation of sentence)
- image_keyword: string (Keyword used for emoji and visual hint association)

6.2 Japanese Kanji JSON Schema (`data/kanji.json`)
Root Object:
{
  "branches": [ BranchObject, ... ]
}

BranchObject:
- id: string (Unique identifier, e.g., "nature_kj", "numbers_kj")
- name_ja: string (Japanese category name, e.g., "自然と天候")
- name_en: string (English category name, e.g., "Nature & Weather")
- icon: string (Category emoji icon, e.g., "🌲")
- characters: Array of CharacterObject

CharacterObject:
- id: string (Unique identifier, e.g., "kj_tree", "kj_sun")
- kanji: string (Single ideogram glyph, e.g., "木")
- onyomi: string (On-reading in Katakana + romaji, e.g., "モク (moku) / ボク (boku)")
- kunyomi: string (Kun-reading in Hiragana + romaji, e.g., "き (ki) / こ (ko)")
- meaning_ja: string (Japanese definition, e.g., "き")
- meaning_en: string (English definition, e.g., "tree / wood")
- strokes: integer (Total stroke count, e.g., 4)
- level: integer (Hierarchy depth: 0=root, 1=derivative, 2=compound)
- parent_id: string | null (ID of parent character, or null for root)
- components: array of strings (Constituent ideograms, e.g., ["木"])
- example_word: string (Compound word with kanji, e.g., "木曜日")
- example_word_reading: string (Hiragana reading + romaji, e.g., "もくようび (mokuyoubi)")
- example_word_kana: string (PURE KANA ONLY without kanji, e.g., "もくようび")  <-- MANDATORY FIELD
- example_word_meaning_ja: string (Japanese definition, e.g., "週の第5日")
- example_word_meaning_en: string (English definition, e.g., "Thursday")
- example_sentence_ja: string (Authentic Japanese sentence with kanji)
- example_sentence_reading: string (Full sentence in Hiragana furigana)
- example_sentence_en: string (English translation of sentence)
- image_keyword: string (Visual hint association keyword)

8. ARCHITECTURAL MODULE IMPLEMENTATION DETAILS
================================================================================

8.1 App Controller & Router (js/app.js)
The application acts as a single-page reactive controller:
- State Machine:
  * `currentMode`: 'hanja' or 'kanji'
  * `currentView`: 'tree', 'test', or 'settings'
  * Data caches: `dataHanja` and `dataKanji` stored in memory for zero-latency toggling.
- Event Delegation:
  * Tab bar clicks intercept default anchors, route via `window.location.hash`.
  * Hash change listener sanitizes route, activates the target view, and invokes
    the respective view refresh method (`TreeView.refreshNodeStates()`, `TestMode.activate()`, etc.).

8.2 Mode-Scoped LocalStorage Abstraction (js/storage.js)
To prevent cross-language data contamination, every data structure in localStorage
is keyed by the active mode prefix:
- `${mode}_learned`    -> Array of IDs marked as learned.
- `${mode}_srs_cards`  -> Key-value map of card SRS states.
- `${mode}_stats`      -> Cumulative review count, current streak, last active timestamp.
- `hk_active_mode`     -> Global string preserving user's language selection across reloads.

8.3 Tree View & Category Quiz Header (js/tree-view.js)
- Renders the `.branch-header` at the top of the active branch.
- Contains `.btn-category-quiz`:
  * Displays a lightning badge with the count of learned characters in this category.
  * If `learnedCount === 0`: has class `.is-empty`. Clicking triggers an alert:
    "⚠️ 아직 이 카테고리에서 학습 완료한 한자가 없습니다. 한자 카드를 클릭해 먼저 '학습 완료'로 표시해주세요!"
    (or Japanese equivalent).
  * If `learnedCount > 0`: calls `TestMode.startCategoryQuiz(branch)`.

8.4 Character Detail Modal & Stroke Animator (js/detail-modal.js)
- Activated by clicking on any unlocked tree node.
- Initializes `new HanziWriter('character-writer-target', charSymbol, { ... })`.
- Stroke animator options:
  * `width: 160, height: 160, padding: 10`
  * `strokeColor: '#231f1d'` (calligraphy ink)
  * `radicalColor: '#c53030'` (vermilion red)
  * `strokeAnimationSpeed: 1.2, delayBetweenStrokes: 180`
- Pure Kana Display Rule:
  In Japanese mode, renders:
  <strong class="example-kanji-title">${char.example_word}</strong>
  <div class="example-kana-sub">かな: <span class="kana-pure">${char.example_word_kana}</span></div>
  <div class="detail-reading">${char.example_word_meaning_ja}</div>
  <div class="detail-en">${char.example_word_meaning_en}</div>

8.5 Anki SM-2 Spaced Repetition Engine (js/test-mode.js)
- Flashcard front displays ideogram and image hint emoji.
- Flashcard back reveals readings, meanings, example words (with pure kana in Japanese),
  and sentences with furigana.
- Renders 4 grading buttons with dynamic preview intervals:
  * Again (0): Interval resets to 1 day; repetition resets to 0.
  * Hard  (1): Interval = 1 day (or interval * 1.2).
  * Good  (2): Interval advances based on ease factor.
  * Easy  (3): Interval advances with bonus ease factor increment.
- Category Banner:
  When initiated via `startCategoryQuiz(branch)`, renders top bar:
  `[← 트리로 돌아가기]` with category icon, name, and `[카테고리 퀴즈]` badge.
  Exiting resets `currentCategory = null` and returns to `#tree`.

8.6 Service Worker & Offline Caching Engine (sw.js)
- Cache Bucket: `hanja-kanji-learner-v3`
- Pre-caches all 15 core files during the `install` lifecycle event.
- During `activate`, purges all obsolete cache versions (`v1`, `v2`, etc.).
- During `fetch`, serves cached assets instantly; falls back to network; clones
  and saves successful GET responses into cache for permanent offline persistence.

10. CORE ALGORITHMS
================================================================================

10.1 SuperMemo SM-2 Algorithm Implementation
Given a flashcard with state `{ interval, repetition, efactor }` and user grade `g` (0 to 3 mapped to 0, 2, 4, 5):

1. Update Ease Factor (efactor):
   efactor' = efactor + (0.1 - (5 - g) * (0.08 + (5 - g) * 0.02))
   efactor' = max(1.3, efactor')

2. Update Repetition Count & Interval:
   If g >= 3 (Good or Easy):
     If repetition == 0:
       interval = 1 day
     Else if repetition == 1:
       interval = 6 days
     Else:
       interval = round(interval * efactor')
     repetition = repetition + 1
   Else (Again or Hard):
     repetition = 0
     interval = 1 day

3. Update Due Date:
   dueDate = now + (interval * 24 * 60 * 60 * 1000) ms

10.2 Progressive Unlock Logic
In `js/tree-view.js`:
- A character is locked if:
  1. It has a `parent_id` specified, AND
  2. The parent character exists in the current branch, AND
  3. `Storage.isLearned(char.parent_id)` returns false.
- When clicked, a locked character triggers an educational toast:
  "🔒 먼저 부모 한자 [Parent]을(를) 학습하세요!"
  ("🔒 まず親の漢字 [Parent] を学習してください！")

10.3 HanziWriter Character Destruction & Initialization
To avoid memory leaks on mobile devices:
- Prior to mounting a new character, `DetailModal.writer` is inspected. If it exists,
  `DetailModal.writer.destroy()` is called.
- The DOM node `#character-writer-target` is purged of previous SVG nodes before
  constructing the new instance.
