HANJA & KANJI - SUMMARY
=======================

For details see:
  docs/superpowers/specs/2026-11-23-hanja-kanji-rebuild-design.md
  docs/superpowers/plans/2026-11-23-hanja-kanji-rebuild.md

WHAT IT IS
Offline PWA for two people. JLPT N5-N3 kanji (612) and 한국어문회 8급-5급 plus
110 of 4급Ⅱ hanja (610). FSRS scheduling, name#1234 profiles, optional sync
through a private GitHub repo using a per-device token.

ARCHITECTURE
- Python pipeline (tools/) turns pinned public sources into committed JSON,
  stroke files and font subsets (data/, assets/fonts/).
- The app is static ES modules, no build step: Preact + htm for screens,
  ts-fsrs for scheduling (both vendored in vendor/).
- An append-only review log in IndexedDB is the source of truth; card state is
  replayed from it. Sync unions the logs via the GitHub Contents API.
- sw.js precaches everything listed in precache.json (generated by
  tools/gen_precache.mjs) for offline use.

FILE LAYOUT
  index.html, manifest.webmanifest, sw.js, precache.json
  src/data      data loading
  src/engine    fsrs, queue, stats, tree
  src/store     IndexedDB
  src/sync      GitHub client, merge, sync procedure
  src/ui        screens and styles
  src/main.js, src/state.js
  data/         generated ja.json, ko.json, strokes/, LICENSES.md
  assets/       icons and font subsets
  vendor/       vendored libraries
  tools/        data pipeline and its Python tests
  tests/        Node tests (npm test)

INVARIANTS
- No quiz or practice button on single characters or in the detail sheet.
  Practice exists only at the top of a level.
- Practice and study only use introduced cards (at least one counted review).
- Every Japanese example word shows its pure kana directly below it.
- Nothing loads from a CDN or remote origin at runtime. The only network calls
  are to api.github.com, and only for sync.
- Progress is separate per profile and per language. Card IDs are
  "ja:<char>" / "ko:<char>" and never change.
- All paths are relative (./...).
- The sync token lives only in IndexedDB; never in a URL, a log line or the repo.
- After changing app files, regenerate precache.json before committing.
